# Referenzzuordnung für R001 bis R160

Generiert aus `DUI_Designrichtlinien.txt`. Referenzart und Sammelpriorität sind redaktionelle Empfehlungen. Eine Gruppe von Regeln kann gemeinsam in einem Pattern demonstriert werden.

A = früh aufbauen, B = bei konkretem Bedarf, C = kurze Ablauf- oder Entscheidungsnotiz reicht zunächst. Die Priorität bewertet den Aufbau der Sammlung, nicht die Bedeutung der Regel.

Für 113 Regeln gibt es ein geprüftes Muster; für 132 Regeln gibt es ein Muster oder eine Arbeitsnotiz. Fehlendes Material begründet keine Pflicht zu einem eigenen Beispiel. Muster sind keine bestätigten Projektvorgaben; Arbeitsnotizen sind keine Prüfnachweise. Siehe [Auswahlhinweise](reference-strategy.md) und [nächste sinnvolle Referenzen](reference-backlog.md).
