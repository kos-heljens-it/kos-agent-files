# Hypothesengeleitete Diagnose

**Verwenden:** Fehlerursache unbekannt; mehrere plausible Erklärungen.
**Eingaben:** beobachteter Soll-/Ist-Unterschied, betroffener Stand und Umgebung.
**Ergebnis:** belegte Ursache oder verbleibende Hypothesen mit fehlendem Nachweis.
**Stopp:** Ursache bestätigt, notwendiger Zugriff fehlt oder weitere Experimente
bringen ohne neue Daten keinen Erkenntnisgewinn.

1. Reproduktion und Randbedingungen festhalten; Beobachtung von Interpretation trennen.
2. Wenige konkurrierende Ursachen nennen. Für jede vorhersagen, was bei Zutreffen
   sichtbar sein müsste und welche Beobachtung sie widerlegen würde.
3. Die kleinste kontrollierte Prüfung wählen, die Hypothesen unterscheidet.
   Nicht gleichzeitig mehrere Einflussgrößen ändern.
4. Tatsächliches Ergebnis festhalten, Hypothesen verwerfen oder eingrenzen.
5. Ursache von auslösendem Ereignis und Symptomen unterscheiden. Erst nach
   belastbarer Evidenz einen Fix planen; keine bloß plausible Geschichte als Beweis.

Diagnostische Prüfungen bleiben im autorisierten Scope; keine Produktivdaten ändern.
