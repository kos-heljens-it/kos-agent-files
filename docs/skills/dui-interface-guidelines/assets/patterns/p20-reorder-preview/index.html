P20 Reihenfolge mit Vorschau ändern

ARBEITSBEREICH / ABLAUF

Schritte ordnen

Ziehen Sie einen Schritt an die gewünschte Position. Eine Linie zeigt vor dem Loslassen, wo er eingefügt wird. Alternativ können Sie die Schaltflächen verwenden.

Arbeitsschritte

Beim Ziehen ober- oder unterhalb der Mitte eines Schritts erscheint die Einfügelinie. Mit den Schaltflächen ändern Sie die Reihenfolge ohne Ziehen.
