P22 Auslösen und Abbrechen bei Touch

EINGABE / AKTION

Aktion bewusst auslösen

Die Vorschau zählt eine Aktion erst, wenn die Schaltfläche aktiviert wird. Bei Touch kann der Finger vor dem Loslassen aus der Fläche bewegt werden.

Markierung setzen

Tippen oder mit Leertaste beziehungsweise Eingabetaste auslösen. Zum Abbrechen außerhalb der Schaltfläche loslassen.

Bereit.

Ausgelöst: 0

Lokale Vorschau ohne Produktanbindung.
